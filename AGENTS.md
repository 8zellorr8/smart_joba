# Правила работы с репозиторием

- Все коммиты этого проекта направлять в `https://github.com/8zellorr8/smart_joba.git`.
- Использовать аккаунт GitHub `8zellorr8` и локального автора Git `8zellorr8 <286028000+8zellorr8@users.noreply.github.com>`.
- Перед отправкой проверять `origin`, автора коммита и состав изменений. Не менять глобальные настройки Git.
- Новые рабочие ветки именовать с префиксом `codex/`, если пользователь не указал другое имя.
- Добавлять в коммиты только относящиеся к задаче файлы; не копировать соседние проекты и временные материалы.
- Репозиторий публичный: не публиковать секреты, персональные данные, исходные материалы колледжа или локальные базы без отдельного указания пользователя.
- Настройка репозитория не является разрешением на разработку приложения: следовать последним указаниям пользователя о текущем этапе работы.
