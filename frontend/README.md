# Frontend · 1-кезең

React + TypeScript + Vite. Барлық іске қосылған экрандар қазақ тілінде. Сыртқы қаріптер, CDN және бұлттық API қолданылмайды.

## Жергілікті іске қосу

Node.js 24.15+ қажет. Репозиторий түбіріндегі нұсқаулық бойынша API мен PostgreSQL іске қосылған болуы керек.

```powershell
cd frontend
npm ci
npm run dev
```

Ашу: `http://127.0.0.1:5173`. `/api` сұраулары Vite арқылы `http://127.0.0.1:8000` серверіне өтеді. Дайын сборканы API сол origin арқылы береді:

```powershell
npm run build
npm test
```

Аккаунт деректері backend seed пәрменімен дайындалады; парольдер интерфейске немесе Git-ке жазылмайды. Тіркелу, пароль қалпына келтіру және басқа рөлді таңдау 1-кезеңге кірмейді.

## Қауіпсіздік шекарасы

- Сервер беретін сеанс және құқықтар пайдаланылады; браузер рөл бермейді.
- Cookie жіберу: `same-origin`; CSRF токен тек React жадында.
- Құпиясөз тек форма жадында болады және кіру әрекеті аяқталғанда өшіріледі.
- Сеанс серверде аяқталады; желі қатесі кезінде жалған сәтті шығу көрсетілмейді.
- Қолданылмаған келесі кезең құралдары өшірілген және белгіленген; кесте/сабақ саны ойдан алынбайды.

Тесттер API шекарасын оқшаулайды; өнім кодында mock API жоқ. Интерфейс тесттері сервердегі құқықтар мен cookie тексерулерін алмастырмайды.

## Нақты браузерде тексеру

`e2e/stage1-smoke.mjs` іске қосылған `http://127.0.0.1:8000` серверіне қосылады және `../.local/accounts.json` файлындағы бес демонстрациялық аккаунтты пайдаланады. Қолданыстағы Playwright және Chromium қажет; скрипт браузерді жүктемейді және жаңа тәуелділіктер орнатпайды.

```powershell
# Playwright frontend/node_modules ішінде болмаса, орнатылған модуль жолын көрсетіңіз:
$env:PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright'
# Playwright әдепкі браузері болмаса, орнатылған Chromium жолын көрсетіңіз:
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE = 'C:\path\to\chrome.exe'
npm run test:e2e
```

Нәтиже: `../.local/qa/stage1-browser-smoke.json`. Тек бос кіру экранының суреттері сақталады; парольдер, браузер трассалары және аккаунтқа кірген экран суреттері жазылмайды. Тексерулер: бес рөлдің кіруі, сервер рөлі, сеансты қалпына келтіру және аяқтау; қате пароль; рұқсатсыз сұраудың `401` жауабы; сыртқы сұраулардың болмауы; 320/360/768/1280 ендеріндегі бетке көлденең айналдырудың қажет болмауы.
