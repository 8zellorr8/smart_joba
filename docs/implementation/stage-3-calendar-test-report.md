Формы: режим чтения, сохранение ввода после 409/503, отсутствие ложного успеха,
очистка старого расчёта после правки или отмены, блокировка расчёта до сохранения,
повторное подтверждение изменённой нормы, CSRF refresh/retry и явные границы дат.

## Definition of Done модуля

Код разделён на чистые правила, прикладной сервис, HTTP-контракты, модели/миграцию
и KK-экран. Применимые проверки имеют наблюдаемые результаты выше; отложенные
интеграционные проверки обозначены отдельно. Ручной путь выполнен, снимок
сохранён локально, инструкции запуска и контракт обновлены. Идентификатор
кодового набора и результаты содержатся в JSON; Git-коммит содержит этот отчёт.

Единственное предупреждение backend — существующее StarletteDeprecationWarning
о httpx в TestClient; оно не является ошибкой проверки.
