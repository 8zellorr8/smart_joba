## Реализованный результат

- Административные формы создают и исправляют карточки студентов, периоды групп, персональные связи аккаунтов и назначения преподавателей.
- Журнал создаётся по ID подтверждённой учебной нагрузки; реальные строки предпросмотра S1 не применялись.
- Преподаватель видит предварительный состав только разрешённого журнала в интервале назначения; утверждающий читает в своей области.
- Студент получает собственную карточку и интервалы, не общий список группы.
- Пять ролей, существующее расписание и исходные публикации сохранены.

Журнал проведённых занятий, оценки, посещаемость и темы остаются следующей функциональной задачей. Новая таблица состава на дату — предварительный просмотр, не снимок проведённого урока.

До миграции сделан закрытый локальный pg_dump и восстановлен в новой отдельной БД. Для **33 прежних таблиц** совпали число строк и SHA-256 упорядоченного представления строк. Миграция сначала проверена в восстановленной копии, затем локально; прежние данные не изменились.

После заполнения демонабора сделан второй dump и проверено восстановление **41 таблицы**, включая студентов, составы, связь аккаунта, журнал, назначение, историю и квитанции. Данные вновь совпали. Публичный отчёт не содержит исходники, дампы, пароли, персональные записи или внутренние ID.

Миграция: `0007_journal_setup`. При наличии истории downgrade блокируется; для возврата используется проверенная резервная копия. Сами копии и названия восстановленных БД сохранены только в `.local`.

## Как проверить пользователю

1. Открыть `http://127.0.0.1:8000/` и обновить Ctrl+F5; подготовленные аккаунты — в `.local/accounts.txt`.
2. Под admin: «Бөлімдер» → «Студенттер және журналдар»; открыть четыре вкладки. В локальном примере три демо-студента, один журнал английского языка и подтверждённые связи.
3. Под teacher: «Журналдар» → «Құрамды қарау» → дата `29.10.2026` → «Көрсету»; появится предварительный состав.
4. Под student: «Оқу профилім»; доступна собственная карточка и группа, одногруппники не выдаются.
5. Прежняя вкладка «Сабақ кестесі» продолжает открывать опубликованное расписание.
