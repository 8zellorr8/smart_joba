## Существенные случаи

- Параллельное применение одной партии возвращает два успешных ответа с одной записью потребности; разные партии одной исходной ревизии дают один успех и один 409.
- Искусственный сбой после части справочных записей откатывает всю транзакцию; частичных назначений и историй нет.
- Неверные XLSX, макросы, XML-объявления сущностей, превышение объёма и чрезмерно сжатый архив отклоняются до применения.
- Формула без кеша остаётся исходным текстом и вопросом; вычисленное значение сервер не создаёт.
- Подтверждённая правка группы/предмета/семестра не теряется при повторе, а новое значение кабинета из изменённого файла не затирается старой правкой.
- Устаревший запрос не теряет введённые значения формы; ошибка применения не показывает успех. Истёкший CSRF обновляется с одним повтором команды.
- Администратору доступен режим чтения; студент не видит вход в импорт и получает 403 по прямому адресу исходника.
- На 320/360/768/1280 px прокрутка широкой таблицы ограничена её контейнером; проверка строки открывается из первого столбца. Внешних запросов и постоянного хранения секретов в браузере нет.

## Проверка предоставленного S1

Импортёр отдельно прочитал исходный S1 в пределах `Жүктеме!A1:L237`: 236 строк, 12 групп, 98 названий предметов после внешних пробелов. Измерено 0,058 секунды на этом компьютере; это один замер, а не гарантия для любого файла. Контрольная сумма исходника после чтения не изменилась.

Строки 85–86 имеют одинаковый ключ и отличаются преподавателем. Они остаются вопросом, без удвоения потребности. Координаты и прежние наблюдения приложения А ТЗ сохранены; реальные ФИО и исходная книга в коммит не включены.

На текущем компьютере настоящий S1 подготовлен только в локальном предпросмотре: рабочий контекст 2026–2027, `college`, единица нагрузки не подтверждена. Он не применён автоматически. Эти локальные данные не входят в репозиторий и не появятся при клонировании.

## Definition of Done

Код и миграция сохранены; перечисленные AC имеют результаты; полный браузерный путь выполнен на синтетическом наборе; экраны 360 и 1280 px осмотрены; исходный S1 проверен без изменения; результаты записаны здесь и в JSON. Генератор, календарь и публикация в готовность импорта не включаются.

Повторение: `scripts/run.ps1 test`; для браузера — запущенный локальный сайт, установленный Playwright/Chrome и `npm run test:e2e:s1` из `frontend`. Скрипт создаёт синтетические файлы в `.local/qa` и использует отдельный синтетический контекст 2030–2031. Диагностические логи и картинки остаются локально.
