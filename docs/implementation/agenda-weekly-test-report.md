# Главный экран и недельное расписание — отчёт испытаний

Дата: 22.10.2026. База: `ba3eb8573c9652b569fb905d5e7b38a439a56c05`.
Задача: внедрить выбранный вариант 2 в существующий сайт с сохранением функций
и серверных прав. Применены локальный `ui-ux-pro-max` и Product Design
`image-to-code` / `design-qa`.

## Результат

Главный экран показывает опубликованные занятия выбранного дня, фильтр группы,
переход к соответствующей неделе, разрешённый проект и существующие действия.
В редакторе и читательском просмотре появилась общая недельная сетка с
карточкой занятия; прежний список и формы сохранены.

Сетка получает все страницы выбранной недели, проверяет ревизии и целостность
пагинации, отбрасывает запоздавшие ответы. Ошибка не подменяется пустым
результатом или частичным успехом. При смене публикации сбрасывается ресурс
предыдущего снимка. При конфликте ревизии введённая форма сохраняется,
повторное сохранение старой ревизии блокируется.

## Браузерная проверка

Playwright запущен с прямого разрешения пользователя, только против
`127.0.0.1:8000`, с установленным Chromium и существующими локальными
аккаунтами. Вход выполнен обычной формой; нет подмены авторизации, трассировки,
видео, загрузки браузера или записи секретов в отчёт.

- `scheduler`, `approver`, `teacher`, `student`, `admin`: вход, главный экран,
  отсутствие горизонтального переполнения при 320/360/857/1440 px, выход.
- Разрешённые читатели: дата/группа → неделя, сведения о занятии, отсутствие
  редактирования, Escape и возврат фокуса, список и обратно с тем же ресурсом,
  фильтры группы/преподавателя/кабинета, предыдущая/следующая неделя/«Бүгін».
- Преподаватель/студент: нет запросов списка проектов и действия открытия
  проекта; прямой серверный запрос `editor-data` возвращает 403.
- Составитель: прежняя форма одной даты открывается внутри карточки; пока она
  открыта, переходы недели/списка отключены. Изменения расписания не сохранялись.
- Согласующий: проект читается без действия редактирования.
- Составитель: открыты прежние страницы импорта, календаря, генератора и версий;
  нет ошибок интерфейса и переполнения при 360/1440 px.

Тест использует имеющиеся локальные синтетические публикации/проекты с занятиями.
Если их нет, он останавливается с явным сообщением о недостающей фикстуре,
не создаёт и не публикует расписание автоматически.

Запуск при работающем сайте и заранее установленном Playwright:

```powershell
$env:PLAYWRIGHT_MODULE = '<абсолютный путь к установленному пакету playwright>'
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE = '<абсолютный путь к установленному chrome.exe>'
node frontend/e2e/agenda-weekly-smoke.mjs
```

Параметры `SMOKE_BASE_URL` и `SMOKE_ACCOUNTS_FILE` необязательны; сервер
ограничен localhost/127.0.0.1. Отчёт и снимки хранятся только в
`.local/qa/agenda-weekly/`. [Визуальная сверка](../../design-qa.md) завершена
после повторной съёмки исправленного редактора.

транзакции публикации и DOCX ТЗ не изменены. Прямой тест 403 дополняет
существующие backend-проверки прав; UI не считается механизмом авторизации.

лицензией. Шрифт/логотип сохранены локально, внешних CDN нет.

Материалы колледжа, локальные БД, аккаунты и закрытые снимки не включены в
коммит. Данные макета не добавлялись в БД. Очереди ТЗ и следующий отдельный
модуль XLSX не менялись. Ручная проверка выполнена в Chromium; полный аудит
доступности, другие браузеры и работа на реальном телефоне не заявлены.
