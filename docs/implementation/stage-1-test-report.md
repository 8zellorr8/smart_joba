## Дополнительные проверки корректности

- Сервер отклоняет подменённый scope, сторонний Origin/Host, удалённый адрес клиента и запрос без CSRF.
- Истёкшая/отозванная сессия и отключённый аккаунт не открывают закрытое API; отзыв назначения применяется без нового входа.
- Публикация не выдаётся администратору или утверждающему автоматически; читатели требуют подтверждённой связи преподавателя/группы.
- Сессия меняется при повторном входе; в БД хранится только хеш токена.
- Некорректный CSRF отклоняется, а ошибка настройки не выводит секреты.
- Runner отклоняет чужую `.env`; переменные окружения родителя не перенаправляют его миграции на другую БД.
- Остановка проверяет PID и время создания собственного API; чужой/повторно использованный PID в регрессиях не останавливается.
- В браузере проверены 320/360/768/1280 px, восстановление сеанса, выход с последующим 401, очистка пароля после ошибки, отсутствие localStorage/sessionStorage и внешних запросов.

## Повтор проверки

Из корня репозитория: `powershell -ExecutionPolicy Bypass -File scripts/run.ps1 test`. Команда использует отдельную тестовую БД. Для браузерной проверки сначала выполните `start`, затем `npm run test:e2e` из `frontend` с установленным Playwright/Chromium; варианты путей описаны в `frontend/README.md`.

Пароли, данные БД, логи и изображения локального осмотра не входят в коммит. Исходные файлы колледжа в приложение первого этапа не загружались.
