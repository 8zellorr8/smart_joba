# Импорт S1: контракт реализации

Дата: 21.10.2026. Основание: паспорт З1 ТЗ v0.9; REQ-004/006, IMP-001–004/007/008, DATA-001/002/004/005 и блокирующая часть RDY. Это следующая задача очереди 1.

## Вход и ограничения

Поддерживается один шаблон `s1-v1`: заголовки A1:L1 соответствуют предоставленному S1, данные начинаются со строки 2. Лист и последнюю строку пользователь задаёт явно; значения по умолчанию — `Жүктеме` и 237. Заголовок модуля не является идентификатором предмета. Служебные ячейки за установленной областью игнорируются независимо от `dimension` листа.

Учебный год задаётся отдельно, вид данных — `college` или `synthetic`; контекст уникален по области, году и виду данных. Единицы: исходные неуточнённые часы, академические часы, пары или минуты. Единица сохраняется без расчёта длительности занятия и без вывода недельной потребности из семестровой.

Технические пределы — рабочие предположения: файл 10 МБ, общий распакованный объём 64 МБ, отдельный элемент архива 16 МБ, 1000 элементов, коэффициент сжатия до 250, конечная строка до 5000 и текст ячейки до 2000 символов. Проверяются структура XLSX, тип основной книги, повторы имён ZIP, пути, шифрование, XML и макросы. Формулы не исполняются; их исходный текст и сохранённое значение разделены. Отсутствующий кеш требует решения пользователя. Внешние ссылки не загружаются.

## Данные и применение

| Сущность | Назначение |
|---|---|
| ImportContext | Область, учебный год, вид данных и ревизия зависимостей |
| ImportBatch | Неизменная исходная книга, SHA-256, шаблон, область чтения, автор, состояние и ревизия предпросмотра |
| ImportRow / SourceReference | Исходные ячейки до нормализации, координаты, нормализованные значения и отдельные решения пользователя |
| ImportIssue | Независимые вопросы с координатой и состоянием; исправление не удаляет историю исходной ячейки |
| TeachingDemand / DemandRevision | Устойчивый UUID потребности, её текущая редакция, предыдущая редакция, источники и подтверждённые соответствия |
| TeachingAssignment | Назначение преподавателя исключительно для строки без блокирующих вопросов |

Предпросмотр создаёт только промежуточные данные. Применение требует `confirmed=true` и актуальной ревизии партии. Блокировки берутся в порядке область → контекст → партия; действующие изменения и аудит фиксируются одной транзакцией. Повтор уже применённой партии возвращает её результат без новой записи потребности или истории. Сбой откатывает также созданные справочники.

Ключ сопоставления содержит группу, название предмета, индекс, семестр и подгруппу. Кабинет, преподаватель и часы не меняют UUID существующей потребности. Подтверждённые исправления идентифицирующих значений сопоставляются через историю исходных строк. В повторном файле изменённое исходное поле имеет приоритет над старым исправлением этого поля; неподтверждённые соответствия остаются вопросом. Противоречащие исторические соответствия отклоняются с `IMPORT_IDENTITY_AMBIGUOUS`, без произвольного выбора.

Исчезнувшие потребности сохраняются. Составитель видит их список до применения. Повторы ключа, в том числе две строки с различными преподавателями при одинаковой нагрузке, сохраняются в применённой партии как неразрешённые исходники; независимые потребности и назначения для них не создаются.

Исправления пустой подгруппы, кабинета и справочников требует подтверждённого основания. Латинская A и кириллическая А, разные дефисы и похожие ФИО автоматически не объединяются. Курс не вычисляется из кода группы. Сопоставление имён подтверждается человеком и сохраняется вместе с редакцией.

## API

Все маршруты используют серверную сессию, область доступа и безопасный формат ошибок первого этапа. POST дополнительно проверяет CSRF и Origin. Вход и рабочий экран сообщают `stage=2`.

| Маршрут | Действие и доступ |
|---|---|
| GET /api/scopes/{scope_id}/imports | Последние 100 партий; admin/scheduler своей области |
| POST /api/scopes/{scope_id}/imports/s1 | Multipart: file, academic_year, data_kind, sheet, last_row, hour_unit, template; только scheduler |
| GET /api/imports/{id}?offset=0&limit=25 | Предпросмотр, вопросы, различия и отсутствующие записи; лимит страницы до 100 |
| POST /api/imports/{id}/rows/{row_id}/review | expected_revision, corrections, references_confirmed; только scheduler, партия preview |
| POST /api/imports/{id}/apply | expected_revision и confirmed=true; только scheduler |
| GET /api/imports/{id}/rows/{row_id}/history | История потребности с ссылками на обе исходные редакции |
| GET /api/imports/{id}/source | Неизменная исходная книга; admin/scheduler своей области |

Коды: 401 — нет сессии, 403 — нет права/неверный CSRF или Origin, 409 — устаревшая ревизия либо противоречащее соответствие, 413 — превышение объёма, 422 — неверный файл/контекст. Ошибка не содержит исходное тело, пароль или токены. Администратор имеет чтение, но не получает права применять импорт.

## Связь со следующими модулями

`ImportService.unresolved_for_context(db, context_id, groups)` возвращает актуальные вопросы выбранных групп, включая неоднозначные строки без TeachingDemand. Для каждого исходного ключа берётся последняя принятая партия; отсутствие ключа в новом файле старый вопрос не закрывает. Результат нужно использовать перед будущим запуском генератора и включать в снимок его зависимостей.

Изменение контекста повышает ревизию и делает более ранний предпросмотр устаревшим. Снимки генератора и публикации ещё не реализованы; их интеграция выполняется в соответствующих задачах по GEN-004, VER-001/002 и ENG-007. AC-002b до этого остаётся непроверенным. Полная панель готовности, массовые исправления и сложные подгруппы остаются в своих очередях ТЗ.
