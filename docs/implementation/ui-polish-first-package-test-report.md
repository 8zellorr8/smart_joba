# Первый пакет UI/UX — отчёт проверок

Дата: 22.10.2026. База: `e467314234f347caeae6c6f6605308976c190282`.
Задача пользователя: улучшить шрифты, заголовки, поля, кнопки, карточки, таблицы
и статусы с сохранением функций и прав.

Применён установленный `ui-ux-pro-max`: целевые рекомендации UX и React по
семантическим состояниям, переносу подписей, клавиатурному фокусу и статусам,
которые понятны без различения цветов.

## Что изменилось

| Область   | Результат                                                                                                                                                               |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Шрифт     | Неизменённый Inter Variable WOFF2 хранится в проекте, попадает в хешированные `/assets/`, загружается с локального сайта; preload указывает на тот же файл              |
| Заголовки | Общий `PageHeading` располагает надпись раздела, H1 и пояснение последовательно; заголовки генератора, версий и просмотра получили полную ширину                        |
| Поля      | Общая минимальная высота 48 px, текст 16 px, одинаковые границы и скругления; поля даты и времени имеют высоту 48 px                                                    |
| Кнопки    | Общие размеры, перенос длинных подписей, отличимые вторичные и недоступные действия, видимый `focus-visible`                                                            |
| Карточки  | Общие отступы, границы, радиусы и лёгкая тень; существующие разделы и формы сохранены                                                                                   |
| Таблицы   | Закреплённые шапки, чередование строк, табличные цифры, согласованные отступы, прокрутка внутри подписанной области; `scope="col"` у заголовков                         |
| Статусы   | Общий `StatusBadge` с пятью цветовыми тонами и прежними текстовыми подписями; состояние опубликованного редактора сопровождается существующим пояснением запрета правок |

`PageHeading` и `StatusBadge` — компоненты представления без запросов, команд и
проверок разрешений. Бейджи не создают отдельные live-регионы; существующие
`role="status"` и сообщения ошибок сохранены. Неизвестному состоянию назначается
нейтральный тон. Удалены заменённые стили старых бейджей и конфликтовавшие стили
описаний заголовков календаря и редактора.

Серверные обработчики, API-клиенты, условия разрешений, транзакции, модели,
миграции, зависимости и основной DOCX не изменены. Данные колледжа не
применялись; новые задания генератора и публикации при визуальной проверке не
создавались. Для входа использованы существующие закрытые демоаккаунты.

Добавлена одна проверка редактора: опубликованное состояние и пояснение видны,
добавление и изменение занятий недоступны, переход к той же версии работает,
команды изменения не вызываются. Две проверки генератора переведены с поиска
текста непосредственно внутри `<p>` на проверку текста существующего
`role="status"`. После полного frontend-прогона изменялись только стили таблицы,
её CSS-класс, удалённые стили и размещение лицензии; итоговая сборка и форматирование
повторены после этих изменений.

## Ручная проверка итоговой сборки

Среда: Windows, IAB, локальный API и PostgreSQL; ширина области браузера 857 CSS px.
Снимки и технические замеры хранятся только в `.local/qa/ui-polish/`.

| Консоль итоговой сборки                | В журнале вкладки ошибок нет                                                                                                                                                              |

Официальный парный TTF той же ревизии проверен по cmap: казахские
`ӘәҒғҚқҢңӨөҰұҮүҺһІі`, русский алфавит с Ё/ё и английские буквы/цифры имеют
глифы. Происхождение, SHA-256 и лицензия описаны в
[`frontend/src/assets/fonts/README.md`](../../frontend/src/assets/fonts/README.md).

Расчёт контрастности новых пар «текст — фон»: основной текст 11,74:1,
вторичный 6,28:1, акцент 7,84:1; бейджи: нейтральный 5,87:1, информационный
7,87:1, успешный 7,11:1, предупреждение 6,69:1, ошибка 6,32:1. Это проверка
перечисленных цветовых пар, а не полный аудит WCAG.

Проверка охватывает текущую ширину IAB; отдельные размеры 320/360 px и полный
маршрут с экранным диктором не проверены. Системные подписи выбора файла/даты
остаются зависимыми от языка браузера. Сохранение раздела после F5, перестройка
навигации и календарных форм, перестановка блоков читателя и новые функции
относятся к следующим согласуемым задачам.
