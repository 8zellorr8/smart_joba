# Главный экран и недельное расписание — вариант 2

Пользователь выбрал второй **показанный** макет и разрешил менять существующее
приложение. Визуальный источник: [reference-option-2.png](reference-option-2.png),
доска 1983×793 с двумя экранами. Это основа оформления, а не источник данных.

## Реализация

- `WorkbenchHome`: повестка выбранного дня из текущих опубликованных снимков,
  выбор группы и даты, переход к соответствующей неделе, разрешённая версия
  проекта и ссылки на существующие модули.
- `timetable/WeekPanel`: общая недельная сетка редактора и читательского
  просмотра, семь дней, фактическое время, фильтры группы/преподавателя/кабинета,
  предыдущая/следующая неделя, «Бүгін», сведения о выбранном занятии.
- `EditorPage` и `PublicationsPage`: переключение недели и прежнего списка с
  сохранением применённого диапазона и ресурса. В редакторе кнопка «Өңдеу»
  открывает прежнюю форму одной даты; публикации остаются неизменяемыми.
- `workbench.css`: тёмная зелёная панель, светлая рабочая область, бирюзовые
  действия, белые карточки, цветные блоки занятий и видимый фокус. Основа форм,
  таблиц и статусов остаётся в `ui-foundation.css`.

На широком экране справа от сетки закреплена карточка занятия; на узком она
расположена под сеткой. Недельная сетка и мобильная навигация прокручиваются в
своих областях. Табличный список остаётся альтернативой сетке.

Вместо рисованной декорации используются существующий логотип и библиотека
[Phosphor React 2.1.10](https://github.com/phosphor-icons/react) под MIT
([лицензия](../../../frontend/public/assets/Phosphor-LICENSE.txt)); импортируются
только используемые значки. Inter уже включён в проект, загружается локально.

## Данные и состояния

Названия, даты, номера версий, статусы и количество занятий поступают из API.
Вымышленные занятия макета не добавляются в БД. Надпись о демоданных сохраняется.
Пустой день отличается от загрузки и ошибки; есть повторная попытка.

Вся неделя собирается из страниц API с проверкой неизменности версии/ревизии,
смещения, числа записей и отсутствия дублей. Частичный результат не показывается
как полная неделя. Запоздавший ответ предыдущего запроса отбрасывается.
Одновременные занятия располагаются отдельными колонками; это визуальная
раскладка, а не новый алгоритм проверки конфликтов.

Даты дней и месяцев подписываются по-казахски даже в браузере без KK-данных ICU.
«Сегодня» определяется в часовом поясе выбранного опубликованного снимка или
календаря проекта. При отсутствии календаря используется пояс браузера только
для начальной даты просмотра; расчёт часов и серверные данные не меняются.

Серверные права, команды редактирования, CSRF, ревизии, валидатор, согласование
и транзакционная публикация сохранены. Смена снимка сбрасывает ресурс прежней
публикации; сбой сохранения не очищает форму и не сообщает об успехе.
