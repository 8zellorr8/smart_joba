# smart_joba

Проект сайта планирования учебного расписания колледжа.

Техническое задание версии 0.9 собрано в единый документ. Разработка приложения ещё не начата.

Рабочие правила для ИИ-агентов находятся в [AGENTS.md](AGENTS.md).

Основной документ:

- [Полное ТЗ версии 0.9 в Word](docs/spec/v0.9/college_timetable_spec_v0_9_ru.docx) — 15 страниц основного текста и приложения, всего 55 страниц.

В документ включены требования, роли, 125 атомарных критериев приёмки, уровни 20 Must-A и 53 Must-B, точки отсечения 21–25 октября, девять паспортов задач ИИ-агентов, Definition of Done, одностраничная шпаргалка для мамы и сценарий защиты на 300 секунд с планом Б. Прежние ID и очереди сохранены. Проверка документа не является испытанием приложения.

Промежуточные материалы части 2:

- [Часть 2 — паспорта задач и общие правила MVP](docs/spec/v0.9/part-2-agent-passports.md).
- [Карта 73 Must-критериев с уровнями и владельцами](docs/spec/v0.9/part-2-acceptance-map.json).

При постановке задач использовать полное ТЗ; промежуточные материалы сохраняют историю подготовки.
