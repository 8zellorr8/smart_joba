# Smart Joba

Локальная LMS для колледжа с интерфейсом на казахском. Преподаватель ведёт электронный журнал по занятиям опубликованного расписания, а студент видит свои результаты.

| Кто | Где и что можно сделать |
| --- | --- |
| Преподаватель | В «Журналдар» открыть своё занятие, записать тему, отметить посещаемость и поставить оценку от 0 до 100. Исправления сохраняются с причиной. |
| Студент | В «Оқу профилім» → «Менің нәтижелерім» посмотреть собственные оценки и посещаемость, в том числе за время учёбы в прежней группе. |
| Составитель | В «Бөлімдер» импортировать нагрузку S1, задать календарь, составить расписание вручную или запустить генератор и проверить конфликты. |
| Утверждающий | Рассмотреть версию расписания и, при наличии права публикации, открыть её преподавателям и студентам. |
| Администратор | В «Студенттер және журналдар» вести карточки студентов, их связи с группами и назначения преподавателей. |

## Запуск в Windows

Понадобятся Python 3.12+, Node.js `>=24.15 <27` с npm, PostgreSQL 18 и .NET Framework 4.x. Откройте PowerShell в папке `smart_joba`. При первой установке выполните команду с доступом к интернету.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 setup
```

После установки запускайте портал командой

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 start
```

Откройте [Smart Joba на этом компьютере](http://127.0.0.1:8000/). Подготовленные логины и пароли лежат в `.local/accounts.txt`. Скрипт использует отдельный локальный кластер PostgreSQL на порту 55432. Если PostgreSQL установлен в нестандартном месте, укажите путь к папке `bin` в `SMART_JOBA_PG_BIN` перед подготовкой.

## Проверки и остановка

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 status
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 test
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 stop
```

Команда `test` проверяет сервер на отдельной тестовой БД, запускает тесты интерфейса и собирает приложение.
